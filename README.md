# 结构化记忆（测试版）

为 AstrBot 提供本地 SQLite 事实与事件记忆，侧重可追溯、按会话隔离的明确事实。无需额外配置 Embedding 或 Rerank；对话模型仍需支持工具调用，写入和查询会消耗模型 token。

## 适用范围

- 事实保存类别、属性、值和来源；支持有效、未确认、已替代状态及到期日期。
- 事实按当前会话和当前说话人隔离；事件按会话查询，其创建者才能更正或删除。群内参与者因此可能查询同群其他人记录的**事件内容和来源**，请仅记录适合该会话共享的信息。
- 默认自动向模型提供当前发言人在当前会话的已确认事实（可在插件配置中关闭），不注入其他用户的画像。新增“性格”和“关系”类别仅用于发言人明确自述，模型仍可能误判，不能把生成的画像当作准确的心理评价。
- 群聊可选启用近期发言者标识：按会话缓存最近消息，在请求中附带发言者 ID 和昵称，帮助区分同名群友；只保存在内存，默认最多附带 8 条、每条文字最多 180 字。相关内容会发送给所用对话模型，重载、重启或重置对应会话后缓存清空。它不能保证模型总能正确理解人物或代词。
- 群友可在群内发送 `/共享我的画像`，让本群通过群友 ID 查询其已确认的称呼、偏好、性格；个人信息、关系、来源原文及未确认内容不提供。`/关闭画像共享`立即撤销该群授权，不删除记录。默认不共享；要找到目标需要明确的 QQ 号或 @，昵称消歧尚未实现。
- 用户可在私聊发送 `/跨会话画像 开启`，允许其本人画像在同一 AstrBot 平台 ID 的不同会话中使用；`/跨会话画像 关闭`撤销，默认关闭。只使用本人已确认的称呼、偏好、性格；不同平台 ID 不共享。如果多个机器人共用一个平台 ID，此功能不能保证按机器人区分。授权后事实可能在其他群聊的回答中体现，建议开启前确认内容适合共享。
- 模型依据对话决定是否调用记忆工具，不保证每次都保存或召回。角色扮演、玩笑、他人转述等应避免当成事实；模型的判断并非可靠的安全边界。
- 事实检索按类别及属性精确匹配，事件使用字面关键词和日期范围；不会自动理解同义词，也不具备语义向量检索。

## 安装和使用

当前仅验证 AstrBot 4.29.3；将本目录安装到 `data/plugins/astrbot_plugin_structured_memory` 后启用或重载插件。使用支持工具调用的对话模型，并确保所选人格允许此插件提供的工具。

示例：向机器人说“记住我喜欢桂花乌龙”，然后在同一会话提问“我喜欢什么茶”。仅当模型成功调用保存工具后才有记录；若未自动保存，可以明确要求它记住并查看 `/我的记忆`。

- `/我的记忆`：列出当前会话中当前用户的事实，最多 50 条。
- `/删除记忆 ID`：删除该事实及其更正版本；删除前请通过列表核对 ID。
- 事件通过模型工具记录和查询，不会自动创建定时任务或主动提醒。

## 图形化配置

在 AstrBot「插件 → 已安装」中打开本插件的配置，可设置每次事实查询条数（默认 20，范围 1–100）、事件查询条数（默认 20，范围 1–100）、`/我的记忆`列表条数（默认 50，范围 1–200）、群聊近期发言者标识及数量、当前发言人画像注入及上限，以及是否提示模型主动记录明确的稳定事实。关闭主动记录选项只改变给模型的提示，不会禁用保存工具，也不能保证模型绝不主动调用。

这些设置只限制单次查询和展示，**不限制数据库容量或 AstrBot 的对话上下文长度**；对话轮数和压缩策略请在 AstrBot 的配置文件中调整。保存插件配置后如未立即生效，请重载插件。

## 存储与删除

数据库位于 AstrBot 的 `data/plugin_data/astrbot_plugin_structured_memory/facts.sqlite3`。事实和事件包含用户提供的来源文本；应用的聊天历史、日志、其他插件数据及备份是独立副本。删除本插件记录不会删除这些副本。

到期事实会从常规查询中排除，**不会自动从数据库物理删除**；`/我的记忆`仍可能显示到期或历史状态。卸载插件前请按自己的数据保留需求备份或清理插件数据目录。

## 已知限制

这是测试版，不保证比向量检索方案更准确或更省 token。异名同义词、隐含事实、多人代称消歧、自动画像冲突合并、定时提醒、记忆管理 GUI 和备份管理均未实现。跨会话功能仅依据平台 ID 和用户 ID；群内画像共享只提供明确授权的非敏感字段。模型有可能误记或漏记；不要把它作为可靠的个人信息或安全判断系统。

当前实现直接使用 AstrBot 4.29.3 的部分类型接口；其他版本尚未测试。更改数据库结构前请备份数据。

## 本地验证

在插件目录运行 `python tests/test_store.py`、`python tests/test_tools.py` 和 `python tests/evaluate_lookup.py`（需要 Python 3.12+；工具测试需要已安装 AstrBot）。实验方法与已知限制见 [验证记录](docs/EVALUATION.md)。
